# 🧪 Virtual Interactive Chemistry Lab

An interactive, browser-based chemistry lab designed to simulate real-world experiments in a safe and engaging environment. This project allows users to explore chemical compounds, use laboratory equipment, and analyze simulated experiment data through an intuitive drag-and-drop interface.

---

## 🚀 Features

- 🧬 **Chemical Compound Library**  
  Access a wide range of chemical compounds with relevant properties and behaviors.

- ⚗️ **Virtual Lab Equipment**  
  Use common lab tools such as beakers, flasks, burners, and more.

- 📊 **Simulated Data & Metrics**  
  Perform experiments and receive realistic data outputs and measurements.

- 🖱️ **Drag-and-Drop Interface**  
  Easily interact with lab elements through a user-friendly UI.

- 🎯 **Experiment Simulation**  
  Combine compounds, control variables, and observe reactions in real time.

- 🔒 **Safe Learning Environment**  
  Conduct experiments without real-world risks.
